# 冰箱笔记 2.0.0 版本描述

> 用途：微信公众平台「提交审核」→「版本描述」字段
> 定位：全新重构上线版，侧重功能与体验，弱化历史缺陷修复表述

---

## 主版本（推荐直接填写，约 230 字）

冰箱笔记 2.0 全新重构上线。一款帮助家庭与合租人群管理冰箱食材的小程序：1）按分区与层记录物品及保质期，以拟物结构图配合绿/黄/红三色状态快速识别临期，减少遗忘导致的浪费；2）支持通过二维码邀请家人协作，按只读/可读写分配成员权限；3）每日临期订阅消息提醒，及时处理临期食材；4）内置 4 套主题随心切换，全局即时生效；5）已接入微信头像昵称授权与隐私合规能力。本版本已通过全量功能回归验证。

---

## 精简版（约 110 字，用于审核字数受限时）

冰箱笔记 2.0：记录冰箱物品存放位置（分区/层）与保质期，拟物结构图三色识别临期；支持二维码邀请家人协作与权限管理、每日临期订阅提醒、4 套主题切换，并接入微信头像昵称授权与隐私合规。

- 提交前请确认：隐私保护指引已在 MP 后台发布（否则隐私弹窗不会触发），且相关云函数已上传部署。
